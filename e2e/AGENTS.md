# E2E Agent Instructions

- 各テストは`@desktop`、`@mobile`、`@nojs`のいずれかを`tag`で宣言する。タグのないテストは
  どのプロジェクトでも実行されない。本文で`test.skip(project.name)`を使わない。
- 端末固有の操作・レイアウトだけを`@mobile`へ、スクリプトなしの経路だけを`@nojs`へ置く。
  それ以外は`@desktop`に集約し、同じ検証を複数プロジェクトへ広げない。
- 画面・テーマ・端末の組み合わせを機械的に増やさない。テーマ差はアクセシビリティ監査、
  デザイントークンは`design:check`とStorybookが受け持つ。
- 寸法・色・トークン値を直接固定せず、利用者に観測できる振る舞いを検証する。
- 比較対象のないスクリーンショットを保存しない。失敗時の記録はPlaywrightの設定が行う。
- 設定はプリペイントスクリプトが読む`localStorage`へ`addInitScript`で与え、
  ハイドレーション後の再適用を待たない。ハイドレーション待ちは`HYDRATED`を使う。
