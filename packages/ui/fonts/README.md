# Self-hosted Japanese fonts

The source fonts and OFL licenses in this directory are vendored from the Google Fonts repository at
commit `26c5c976d82d50c24a8f0a7ac455e0a7c639c226`.

- `source/zenkakugothicnew`: Zen Kaku Gothic New 400, 500, 700
- `source/hinamincho`: Hina Mincho 400
- `source/dotgothic16`: DotGothic16 400

Production assets are generated by `deno task fonts:generate`; generated WOFF2 files are
intentionally ignored.
