# Self-hosted Japanese fonts

The source fonts and OFL licenses in this directory are vendored from the Google Fonts repository at
commit `26c5c976d82d50c24a8f0a7ac455e0a7c639c226`.

- `source/zen-kaku-gothic-new`: Zen Kaku Gothic New 400, 500, 700
- `source/hina-mincho`: Hina Mincho 400
- `source/dot-gothic-16`: DotGothic16 400
- `source/manrope`: Manrope variable 200–800
- `source/newsreader`: Newsreader variable optical size 6–72 / weight 200–800
- `source/fira-code`: Fira Code variable 300–700

Production assets are generated by `deno task fonts:generate`; generated WOFF2 files are
intentionally ignored.
